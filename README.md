# Sankers Alumni

Honouring Our Namboothiri Mash at 80.

Live site: https://sankers-alumni-angadipuram.a-arangodan.chatgpt.site

## Source

The static site is in `dist/`, including the photo and video gallery. Serve this folder with any static web server.

The registration form requires Student or Teacher, name, year, WhatsApp number and email. It opens a message to the Chairman; visitors must send it in WhatsApp. There is no registration database.

The site is hosted through ChatGPT Sites. This repository is a source copy; changes here are not automatically deployed to Sites.
